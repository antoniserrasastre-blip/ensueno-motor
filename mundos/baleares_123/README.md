# Baleares, 123 a. C.

Mundo para el motor nuevo (`engine/`). Eres un isleño de un poblado talayótico de Mallorca. Este año llegan las naves
de Roma con el cónsul Metelo. Puedes adelantarte a lo que trae Roma o inventar lo tuyo.

- `constitucion.md`: la época en 15–20 líneas. El briefing la carga siempre y manda sobre todo.
- `datos/anacronismos.json`: lo que no existe (bloquea el cierre) y lo que es de fuera (avisa).
- `datos/catalogo.json`: objetos, oficios y habilidades de las islas.
- `inicio.json`: los lugares con los que empieza una partida.
